# Design files

[DESIGN.md](../DESIGN.md) at the repo root is the source of truth for the design system, and the app in `src/` is the real implementation. This folder holds the reference material behind them.

## Current: Margin

[`concept/`](concept) has the static pages we designed Margin from: the system sheet (`00-system.html`), the Visualiser, the cohort view, the student step page and the export dialog. Open any page in a browser. `shoot.sh` re-renders the screenshots in `concept/shots/` with headless Chrome, and `concept/video/` has a short clip of the Visualiser interactions.

The feature issues link these pages next to the Margin screen each one builds on.

## Earlier prototype

These came first and set the scope: which screens exist and what each one has to show. Their look was replaced by Margin.

- [`mockups/`](mockups): the nine prototype screens, generated by `generate.py` with `style.css`
- [`screenshots/`](screenshots): renders of those screens
- [`ai-interaction-analytics-showcase.mp4`](ai-interaction-analytics-showcase.mp4): the 100-second product film

Many issues and `docs/issue-plan.json` still cite these paths, so we keep them where they are. Use them for scope and content, and Margin for how things look.
